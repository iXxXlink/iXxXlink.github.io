# Leo — personal website

A minimal, fully English personal website for Leo, an Agent Engineer at Alibaba and Sichuan University undergraduate alumnus.

Live site: https://ixxxlink.github.io/

## Maintain the content

1. Edit `profile.json`. This is the shared content source for the website and Profile README.
2. Run `python3 scripts/build.py`.
3. Commit `profile.json`, `index.html`, and `PROFILE_README.md` to this repository.
4. Copy the generated `PROFILE_README.md` into `README.md` in `iXxXlink/iXxXlink` to keep the GitHub profile aligned.

Edit `site.template.html` for layout/style changes, then run the same build command. The generated site is static, has no runtime dependencies, and contains no tracking script or backend service.

## GitHub Pages

Publish from the `main` branch and the repository root (`/`). `.nojekyll` disables Jekyll processing. No custom domain or paid hosting is required for the default GitHub Pages address on a public repository.
